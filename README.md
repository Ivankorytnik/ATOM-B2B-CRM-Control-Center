# Production and Sales Plan MVP

Отдельный MVP для подготовки штабного One Page из трех загружаемых файлов:

1. План продаж Excel.
2. Производство / отгрузки Excel.
3. Требования к One Page DOC/DOCX/TXT.

Обработка выполняется локально в браузере. Загружаемые файлы не сохраняются в GitHub.

Основной экран формирует:
- цепочку производство → отгрузка → распределение → выдача → свободный сток;
- B2C / B2B / B2G / Carsharing;
- детализацию B2B / B2G / Carsharing по клиентам;
- недельный график;
- контроль расхождений и неподтвержденных объемов;
- блок «Что изменилось» через локально сохраненную базу сравнения;
- Human in the Loop перед печатью / PDF.
